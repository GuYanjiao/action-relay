## 已完成的代码变化

| 范围 | 已确认的实现 |
|---|---|
| 手表控制 | 录制键居中；开始轻触，停止需长按约 650ms；计时位于按键下方。停止前等待时间包含交互门槛，不应全部计为通信延迟。 |
| 长按反馈 | PNG 分段进度环、提前松手回落动画，以及隐藏/销毁页面时的计时器清理。 |
| 电量显示 | 手机与手表采用低/中/高红黄绿；手表电量资源改用兼容 PNG。 |
| 录制触觉 | 开始触摸发起时短振，按下停止进入长按时立即长振；开关存入 system.storage。触觉是操作反馈，不是相机执行成功证明。未实现声音反馈。 |
| 手机界面 | 移除大型录像按钮，保留紧凑的只读录像状态；状态顺序与手表一致。录像入口主要在手表和快捷磁贴。 |
| 通信授权 | 查询发现缺少权限时，每个当前手表节点自动发起一次授权申请；拒绝/失败后保留手动入口。不是静默授予权限，也未绕开小米运动健康。 |
| 防断连 | 工具页提供省电、自启动、后台锁定三步引导及 companion 设置入口。不能据此证明某次断线必然由后台清理造成。 |
| 资源与打包 | 扫描候选最多 24 项；旧生成包/目录在打包前清理；APK 中间产物清理。手表编译目录保留给编译后页面回归；保留公开证书供包配对验证。 |
| 构建兼容 | 修复 Vela 编译模块名适配，声明 storage/vibrator feature，同步更新包特性校验。 |
