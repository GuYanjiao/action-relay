## 边界

此次真实迁移的是帧生成、CRC、通知重组和控制/GPS队列，Java为调用适配器；Android蓝牙、GNSS、小米SDK、UI及既有控制确认状态机仍使用Java。没有静默Java核心回退。

本地仅编辑、静态检查和发布产物检查，所有编译及可执行回归均在云端。没有执行手机安装、真实相机控制、Android JNI实机加载或能耗A/B测量，因此没有宣称省电比例或真机延迟改善。开发板仓库未修改。
