## 真机与协议边界

[官方协议及实现依据](../dji-watch-telemetry.md#044-回放及拍照控制)：官方定义了 1D04 模式切换和 1D03 拍录，但没有单独退出回放的命令，也未保证重复设为当前模式必然退出回放。本实现会等真实回报；若相机不支持，即超时并停止后续拍摄。不能将上述状态机测试称为 Action 4 回放退出成功的证据。

仍需真机核对：按钮单圈效果、计时与侧边文字、相机实际回放退出、拍照/倒计时/连拍回报、照片是否成功写卡、快速开始后停止及断线恢复。

未找到公开 R SDK 中分辨率/帧率写入定义，规格控制仍只读，未使用 reserved 字段或盲切 QS 键伪造规格设置。
