# Action 4 可扩展的手表信息

核对日期：2026-10-26。依据大疆官方 [R SDK 数据段文档](https://github.com/dji-sdk/Osmo-GPS-Controller-Demo/blob/92fe23e5a749f189593f980a26a105c3bb66aa1c/docs/protocol_data_segment_CN.md)，对应官方仓库当前提交 `92fe23e5a749f189593f980a26a105c3bb66aa1c`。0.4.2 已接入剩余可录时长和普通视频分辨率/帧率显示的代码，实际 Action 4 回报仍待真机验证。

| 信息 | 官方路径 | 当前实现与建议 |
|---|---|---|
| 录像状态、计时、电量 | 1D02 | 已解析并显示，保留新鲜度判断。 |
| 分辨率、帧率、画幅 | 1D02 | 0.4.1 底部显示普通视频的分辨率/帧率；不把慢动作倍率或连拍数当 fps，主界面省略画幅。 |
| 增稳模式 | 1D02 | 尚未解析/转发；适合详情页图标或短标签。 |
| SD 剩余空间、可录时长 | 1D02 | 0.4.2 读取偏移 23 的 uint32 秒数，界面按小时、分钟显示（不足一分钟为 <1分）；缺失和 0xffffffff 显示未知。容量仍保留于诊断数据，不用码率估算冒充相机回报。 |
| 过热等级 | 1D02 | 0.4.3 已转发手表，3 点方向显示温度状态；偏移 30 的 temp_over 是 0–3 级，只有等级，不能显示为实际摄氏温度。 |
| 自定义模式、预录/循环、倒计时、延时间隔 | 1D02 | 大多未解析；按当前拍摄模式选择显示，避免挤满主界面。 |
| 休眠、模式预切换 | 1D02 | 已有部分解析，用于准确提示过渡/不可控状态。 |
| 型号、设备名称、固件/SDK 版本 | 0000 查询 | 尚未实现查询；适合低频的相机详情，不应高频轮询。 |

最优先建议：**剩余可录时间、拍摄规格、过热告警**。多数来自现有状态订阅，扩展解析与有界状态转发即可，不需要每个字段额外轮询。短报文缺失的字段显示未知，不能补零；Action 4 固件实际回传的字段和值仍须实测。

公开 `1D04` 模式切换指令只定义设备标识、模式与保留字节，没有分辨率或帧率设置字段；状态推送字段也不是可写参数。本轮不添加猜测的设置命令，所以底部规格为只读。SD 单位按协议 MB 展示，GB 使用十进制换算；字段缺失或无效显示未知。

该文档还包含面向其他型号的新模式和 1D06 扩展，不能直接认为 Action 4 支持全部模式。FOV 字段标记为保留，不能当成可靠视角信息；未在这份公开 R SDK 中找到实时预览、实际温度数值、音频电平或完整曝光参数的可用回传定义。

手机 GPS 的速度、高度、精度等也可单独转发给手表，但它们来自手机测量，不是相机回报；显示时应标明来源。GPS 发送不等于视频中已验证写入。
