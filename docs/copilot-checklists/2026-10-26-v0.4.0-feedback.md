# v0.4.0 手表录制反馈清单

## 官方能力核对

- [x] 查阅 Xiaomi Vela 官方振动接口文档。

- [x] 在手表工具页增加录制反馈开关。
- [x] 使用 `@system.storage` 持久化开关状态。
- [x] 在 Vela manifest 中声明 `system.storage` 与 `system.vibrator` feature。
- [x] Android 与手表版本提升到 0.4.0 / versionCode 9。
