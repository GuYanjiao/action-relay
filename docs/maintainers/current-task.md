## 必须继续完成的运行流程

1. 将 HRS 与 FE95 接入同一个 S4 物理连接，另一条连接用于相机。当前心率/诊断仍各有运行所有者，不能长期占用诊断连接阻止心率。
2. 接入 FE95：读取 0050、发现并订阅 005E、串行写入 005F、按 MTU 分块、SAR/L2/PB/认证组合。加密计算放在串行工作线程，避免阻塞蓝牙回调和 ANT 主循环。Zephyr 取消 GATT 或退订不等于参数立即可重用，必须等待对应回调结束。
3. 仅本地 USB 导入用户自己的 AuthKey；用户确认已有 AstroBox 设备或 AuthKey，尚未读取任何真实密钥。不要让用户贴密钥到聊天，不得使用公开示例他人的密钥，不上传真实密钥，不做账号或绑定变更。
4. 实测身份匹配的应用消息、relayHello 和 ping/pong，再接相机。当前模块尚未组成真实运行通道；不能把合成向量或编译通过当作互通证明。
5. 相机侧：扫描后只连接用户选定的设备，确认 FFF0/FFF4/FFF5，移植现有 Android DjiSession 的 0x00/0x19 授权握手；生成开发板独立且持久化的 controllerId 和六字节身份，只在相机明确授权成功后记住设备。不要复用手机身份，不要自动选附近其他相机。
6. 相机状态订阅、命令票据/去重/确认、过期禁用、停止覆盖未确认开始，任何超时都不重放快门。最后验收 ANT+、踏频、相机并发和恢复。
