## 本次完成

- 控制先派发到 GATT，合并同一轮 UI 刷新；结果捎带对应状态，减少手表确认后再取状态的一次往返。结果队列有界、合并受理与终态、隔离旧回调及旧会话。
- 控制期间申请 BLE 高优先级，结果或超时后恢复均衡；保持单 GATT 操作、GPS 合并及相机确认规则。记录手机受理→相机结果、GATT 排队、结果队列→SDK 回调的本机单调时钟耗时，不记录地址或位置，也不把 SDK 回调称为手表已收到。
- 手机界面按系统夜间模式选择完整浅/深色调色板，并同步状态栏、导航栏和弹层颜色；手表仍保持纯黑。
- 仅迁移有成功配对标记的历史设备，地址/名称/时间只在协议 ready 后保存；冷启动恢复配对上下文。重连按钮可一次开启中转并连接；最多 5 次有界退避，首轮立即调度，关闭/忘记/搜索/换设备会取消旧任务。蓝牙重新打开或授权后返回应用可恢复记忆设备重连。相机面板显示上次成功时间和忘记入口。
- 新增重连取消/旧任务隔离、结果队列优先级/上限和手表捎带状态/旧会话回归，均接入云端；随后提升到 0.3.5 / versionCode 8。
