## 本轮行为与边界

控制先派发到相机，再发受理消息和刷新 UI；终态带同一版本的相机状态，避免手表确认后再查询一次。较旧或不合法的捎带状态回退到查询，不能绕过实际相机确认。结果队列有界并合并同一请求的受理与终态，发送项身份校验隔离迟到回调。最近退出的会话不会覆盖当前手表状态。

控制期间申请低延迟 BLE 参数，结果/超时后恢复均衡参数；请求由系统和设备处理，不保证必然改变连接间隔。高优先级的耗电折中参考 [Android BluetoothGatt 官方说明](https://developer.android.com/reference/android/bluetooth/BluetoothGatt#requestConnectionPriority(int))。本轮没有降低停止确认标准或缩短超时来制造提速。

手机连接日志分开记录 GATT 排队、手机受理至相机结果、结果排队至 SDK 回调，均使用手机本机单调时钟；不记录地址/经纬度，不把 SDK 回调当作手表显示完成。尚无真机前后对比，不能宣称降低了多少毫秒。
